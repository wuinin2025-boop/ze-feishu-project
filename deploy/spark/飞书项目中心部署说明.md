# SPARK 部署说明

## 运行位置

- 服务器：本地 SPARK。
- 项目目录：`/home/admin/ze-feishu-xiangmuzhongxin`。
- 仓库：`wuinin2025-boop/ze-feishu-project`，使用 `main` 分支。
- 用户服务：`ze-feishu-control.service`、`ze-feishu-sync.service`、`ze-feishu-sync.timer`。
- 定时：北京时间每天 09:00、17:00。服务失败后间隔 5 分钟重试，半小时最多启动 3 次。
- 凭据与访问配置：`/home/admin/.config/ze-feishu-project/`，不进入代码仓库。
- 运行核对报告：`/home/admin/.local/state/ze-feishu-project/invoice-verification.md`，不修改仓库中的历史报告。

控制台端口由服务器私有配置中的 `HOST` 和 `PORT` 决定。程序使用 `BASE_PATH` 指定页面路径。

## 后续更新

在项目目录拉取 `main` 最新代码、安装锁定版本依赖并执行测试，再重启控制台用户服务。
运行一次同步服务，并检查核对结果及下一次定时时间。

```bash
export PATH="$HOME/.local/bin:$PATH"
cd /home/admin/ze-feishu-xiangmuzhongxin
git pull --ff-only origin main
npm ci
npm test
systemctl --user restart ze-feishu-control.service
systemctl --user start ze-feishu-sync.service
systemctl --user status ze-feishu-sync.service --no-pager
systemctl --user list-timers ze-feishu-sync.timer --no-pager
```

修改服务配置后，将 `deploy/spark/` 中三个服务文件安装到 `~/.config/systemd/user/`，执行 `systemctl --user daemon-reload`，再重启对应服务。

## 同步规则

新项目默认经营项目；旧记录分类为空或为“选择项目类型”时补为经营项目，人工维护的经营、走账、行政分类保留。
项目进度表仅为缺失的经营项目创建一条默认任务，预立项项目不创建任务。
同一来源的同一发票号跨项目时，按项目编号分别保留明细，并追加跨项目备注；源记录原备注保留。
源表和旧项目人工补录表保持只读。
