# 老板驾驶舱 V5 设计方案

## 目标

建设一个面向老板使用的飞书驾驶舱，并且驾驶舱数据不依赖本地脚本手动刷新。

老板打开驾驶舱后，需要快速回答四个问题：

- 现在整体业务盘子和现金情况怎么样？
- 接下来一周、下个月预计开票和回款多少？
- 哪些项目已经逾期，负责人是谁，金额和时间是什么？
- 当前数据是否完整、可信，哪些地方还需要人工确认？

## 已确认的飞书能力

- 飞书多维表格仪表盘支持添加折线图、柱状图、饼图等图表组件：https://www.feishu.cn/hc/zh-CN/articles/360049067678
- 飞书仪表盘支持筛选条件和切片器组件，可以按公司、分类、时间等维度筛选：
  - https://www.feishu.cn/hc/zh-CN/articles/493084579750-%E5%9C%A8%E4%BB%AA%E8%A1%A8%E7%9B%98%E4%B8%AD%E7%AD%9B%E9%80%89%E6%95%B0%E6%8D%AE
  - https://www.feishu.cn/hc/zh-CN/articles/660924361907-%E4%BD%BF%E7%94%A8%E5%88%87%E7%89%87%E5%99%A8%E7%BB%84%E4%BB%B6%E7%AD%9B%E9%80%89%E4%BB%AA%E8%A1%A8%E7%9B%98%E6%95%B0%E6%8D%AE

## 总体规则

- `项目分类管理` 只在 `项目总览表` 里人工维护。
- 老板驾驶舱只纳入 `经营项目` 和 `走账项目`。
- `行政/内部项目` 不进入老板驾驶舱。
- `总项目` 指 `经营项目 + 走账项目`，不包含行政/内部项目。
- `经营项目` 和 `走账项目` 必须分开展示、分开统计、分开看风险。
- `总项目` 只作为辅助汇总，不作为老板判断经营质量的主口径。
- 驾驶舱中所有开票、收款、未收款、计划开票、预计回款等金额指标，都不能计算 `行政/内部项目`。
- 保留当前已有的 `选择公司` 筛选，并让它影响所有指标卡、图表和清单。
- 优先使用飞书公式、查找引用、视图、仪表盘筛选和飞书自动化流程。
- 不再用本地脚本刷新老板驾驶舱。
- 不写入任何 `源_` 表。
- `（旧项目）开票计划补录表` 当前仍处于人工补录阶段，不创建、不更新、不清理、不迁移其中的数据。

## 驾驶舱结构

### 顶部全局筛选

保留现有的公司筛选，并补充兼容的筛选条件。

默认状态下，驾驶舱不应该只靠 `项目分类` 筛选来区分数据，而是直接并排展示 `经营项目` 和 `走账项目` 两套数据。`项目分类` 筛选只用于临时钻取。

- `选择公司`：全部 / 集熠 / 冶堂 / 亦所
- `项目分类`：全部 / 经营项目 / 走账项目
- `时间范围`：本月 / 下月 / 自定义

为了让筛选能作用到所有组件，驾驶舱涉及的数据源表都需要有公司字段，可以是原生字段，也可以是通过关联项目带出的引用字段：

- `项目总览表.立项公司`
- `项目开票计划表.立项公司`
- `开票明细统一表.立项公司`
- `项目线索表.立项公司`，如果字段名不同，需要确认实际字段

### 第一屏：老板判断区

第一屏的目标是让老板在 30 秒内判断当前公司经营和现金流状态。

第一屏分成三块：

- `经营项目总览`：老板判断真实经营质量的主视角
- `走账项目总览`：老板判断走账规模、回款和占用风险的独立视角
- `总项目辅助汇总`：只汇总 `经营项目 + 走账项目`，用于看整体规模

`经营项目总览` 指标卡：

- `经营项目数`
- `经营项目已开票金额`
- `经营项目已收款金额`
- `经营项目未收款金额`
- `经营项目下周预计开票`
- `经营项目下周预计回款`
- `经营项目下月预计开票`
- `经营项目下月预计回款`
- `经营项目风险项目数`

`走账项目总览` 指标卡：

- `走账项目数`
- `走账项目已开票金额`
- `走账项目已收款金额`
- `走账项目未收款金额`
- `走账项目下周预计开票`
- `走账项目下周预计回款`
- `走账项目下月预计开票`
- `走账项目下月预计回款`
- `走账项目风险项目数`

`总项目辅助汇总` 指标卡：

- `总项目数`：统计 `经营项目 + 走账项目`
- `线索项目数`：有效线索数量；不展示线索逾期跟进字段
- `总项目已开票金额`：统计纳入驾驶舱的有效开票金额
- `总项目已收款金额`：统计纳入驾驶舱的有效回款金额
- `总项目未收款金额`：`总项目已开票金额 - 总项目已收款金额`
- `总项目风险项目数`：存在逾期开票、逾期回款、金额异常、未分类等问题的项目数量

下周、下月预计开票和预计回款必须分别放在 `经营项目总览` 和 `走账项目总览` 中，不使用混合口径作为主指标。

图表：

- `经营项目月度趋势折线图`：直接使用飞书仪表盘多数据源完成
  - 每月计划开票金额
  - 每月实际开票金额
  - 每月实际回款金额
  - 每月未收款余额

- `走账项目月度趋势折线图`：直接使用飞书仪表盘多数据源完成
  - 每月计划开票金额
  - 每月实际开票金额
  - 每月实际回款金额
  - 每月未收款余额

- `总项目月度趋势折线图`：辅助查看整体现金流规模
  - 每月计划开票金额
  - 每月实际开票金额
  - 每月实际回款金额
  - 每月未收款余额

- `项目结构图`
  - 经营项目
  - 走账项目
  - 线索项目
  - 逾期项目

### 第二屏：老板问责区

第二屏的目标是让老板知道具体该问谁、问什么、什么时候逾期、金额是多少。

清单一：`逾期开票项目清单`

建议拆成两个清单或两个视图：

- `经营项目逾期开票清单`
- `走账项目逾期开票清单`

必须包含：

- 项目名称
- 项目分类管理
- 所属公司
- 项目负责人
- 计划开票日期
- 开票逾期天数
- 未开票金额

清单二：`逾期回款项目清单`

建议拆成两个清单或两个视图：

- `经营项目逾期回款清单`
- `走账项目逾期回款清单`

必须包含：

- 项目名称
- 项目分类管理
- 所属公司
- 项目负责人
- 预计回款日期
- 回款逾期天数
- 未收款金额

清单三：`高额未收款项目`

建议拆成两个清单或两个视图：

- `经营项目高额未收款清单`
- `走账项目高额未收款清单`

必须包含：

- 项目名称
- 项目分类管理
- 所属公司
- 项目负责人
- 已开票金额
- 已收款金额
- 未收款金额
- 最近预计回款日期

清单四：`线索项目清单`

建议包含：

- 线索名称
- 所属公司
- 负责人
- 预计金额，使用 `项目线索表.预计金额`
- 线索状态

清单五：`数据可信度检查`

建议包含：

- 未分类项目数
- 未匹配发票数
- 金额异常计划数
- 缺少开票计划的项目数
- 旧项目补录未完成数量

## 数据来源

### 直接使用的现有表

- `项目总览表`：项目分类、公司、负责人、项目层级汇总字段
- `项目线索表`：线索数量、有效线索、预计金额
- `项目开票计划表`：计划开票和预计回款
- `开票明细统一表`：实际开票和实际回款
- `（旧项目）开票计划补录表`：当前只读参考，人工补录完成前不作为自动刷新源

已有或应保留字段：

- `关联项目`
- `项目编号`
- `项目名称`
- `项目分类管理`
- `老板驾驶舱分组`
- `计划开票金额`
- `计划开票日期`
- `预计回款日期`
- `实际开票金额`
- `实际收款金额`
- `未开票金额`
- `未收款金额`
- `开票逾期天数`
- `回款逾期天数`
- `匹配状态`

需要新增或确认的字段：

- `立项公司`：从 `关联项目` 查找引用
- `当前项目负责人`：从 `关联项目` 查找引用
- `下周预计开票金额`：公式字段
- `下周预计回款金额`：公式字段
- `下月预计开票金额`：公式字段
- `下月预计回款金额`：公式字段
- `开票月份`：用于月度趋势图的月份字段
- `回款月份`：用于月度趋势图的月份字段

上述预计金额、未开票金额、未收款金额相关公式必须排除 `行政/内部项目`。

### `开票明细统一表` 需要的字段

已有或应保留字段：

- `关联项目`
- `项目编号`
- `项目名称`
- `项目分类管理`
- `老板驾驶舱分组`
- `开票金额`
- `收款金额`
- `欠款金额`
- `开票日期`
- `收款日期`
- `是否纳入统计`
- `匹配状态`
- `抵消状态`

需要新增或确认的字段：

- `立项公司`：从 `关联项目` 查找引用
- `当前项目负责人`：从 `关联项目` 查找引用
- `开票月份`：用于月度趋势图的月份字段
- `回款月份`：用于月度趋势图的月份字段
- `有效开票金额`：公式字段，未纳入统计时为 0
- `有效收款金额`：公式字段，未纳入统计时为 0

上述有效金额公式必须同时满足：

- `是否纳入统计 = 是`
- `项目分类管理 != 行政/内部项目`

### 月度趋势图口径

月度趋势折线图直接用飞书仪表盘多数据源完成，不新增任何月度汇总表。

按月份分组统计：

- 从 `项目开票计划表` 统计每月计划开票金额
- 从 `开票明细统一表` 统计每月实际开票金额
- 从 `开票明细统一表` 统计每月实际回款金额
- 从 `开票明细统一表` 或项目层汇总字段统计未收款余额

每条数据源都必须过滤 `项目分类管理 != 行政/内部项目`。

建议在飞书仪表盘中建立三组趋势图：

- `经营项目月度趋势`：过滤 `项目分类管理 = 经营项目`
- `走账项目月度趋势`：过滤 `项目分类管理 = 走账项目`
- `总项目月度趋势`：过滤 `项目分类管理 in 经营项目、走账项目`

老板优先看经营项目趋势，走账项目趋势单独看，总项目趋势只用于辅助判断整体现金流规模。

## 自动化策略

### 不再用本地脚本刷新驾驶舱

老板驾驶舱的指标卡、图表、清单应直接绑定飞书表和视图。

当底层表记录、公式、查找引用字段发生变化时，驾驶舱通过飞书自身能力刷新。

### 飞书自动化流程的用途

飞书自动化流程只用于确实需要自动复制或汇总记录的地方：

- 三张 `源_开票明细` 自动进入 `开票明细统一表`
- 审批通过的 `源_立项申请` 开票计划自动进入 `项目开票计划表`

### 仍需要人工在飞书界面配置的部分

当前可用工具能创建多维表格的数据表、字段、记录和视图，但没有直接编辑飞书仪表盘组件的接口。

因此老板驾驶舱页面本身需要在飞书界面中手动重建：

- 添加指标卡
- 添加折线图
- 添加表格组件
- 添加公司筛选器或切片器
- 把每个组件绑定到指定的数据表或视图

## 实施顺序

1. 确认所需字段是否已存在，缺失的字段优先用公式或查找引用补齐。
2. 为每个驾驶舱组件建立对应视图。
3. 在飞书仪表盘中手动重建老板驾驶舱组件。
4. 配置全局公司筛选器，确保所有组件都跟随公司筛选变化。
5. 配置飞书自动化流程，让源数据自动进入目标业务表。
6. 纯飞书驾驶舱验证通过后，隐藏或停用脚本生成的 `老板驾驶舱关键数据表`。
7. 保留 `verify:invoice` 作为可选审计命令，但不再作为驾驶舱刷新步骤。

## 已确认口径

- 月度折线图已确认直接使用飞书仪表盘多数据源完成。
- 线索预计金额已确认使用 `项目线索表.预计金额`。
- 线索逾期跟进字段不在驾驶舱展示。
- `下周预计开票/回款` 已确认放到第一屏指标卡。
- 经营项目和走账项目必须分开展示，不能只靠一个项目分类筛选切换查看。
- 总项目只作为辅助汇总，不替代经营项目和走账项目的独立判断。

## 验收标准

- 修改 `项目总览表.项目分类管理` 后，不运行本地脚本，驾驶舱分组也能自动变化。
- 公司筛选能影响所有指标卡、图表和清单。
- 行政/内部项目不进入老板驾驶舱总计。
- 行政/内部项目不进入任何开票、收款、未收款、计划开票、预计回款金额统计。
- 驾驶舱能同时展示经营项目、走账项目、总项目、线索项目、逾期开票项目、逾期回款项目。
- 经营项目和走账项目的数据默认并排展示，老板不需要切换筛选才能对比两类项目。
- 驾驶舱包含经营项目、走账项目、总项目三组月度趋势：计划开票、实际开票、实际回款、未收款余额。
- 月度趋势折线图直接使用飞书仪表盘多数据源完成，不依赖本地脚本刷新。
- 第一屏指标卡分别包含经营项目和走账项目的下周预计开票、下周预计回款、下月预计开票、下月预计回款。
- 逾期开票和逾期回款清单能展示项目、公司、负责人、日期、逾期天数和金额。
